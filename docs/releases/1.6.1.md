# OpenCleaner 1.6.1

Les résultats se mettent maintenant à jour automatiquement après un nettoyage, même si certains fichiers sont ignorés, si une erreur survient ou si vous annulez l’opération.

- Les fichiers réellement supprimés disparaissent de la liste et ne sont plus comptés dans le volume détecté.
- Les fichiers encore présents, notamment ceux qui sont verrouillés ou restaurés après une interruption avec sauvegarde, restent affichés.
- La correction couvre les catégories de nettoyage, le nettoyage rapide, les doublons, les caches développeur et les fichiers sensibles. Les résultats déjà ouverts dans les autres écrans sont également actualisés.
- La santé du PC est recalculée lorsque vous revenez sur cet écran après un nettoyage.
- Cette actualisation ne relance pas une analyse complète des fichiers et ne modifie pas votre choix de sauvegarde.

Validation : tests sur des fichiers temporaires pour les suppressions complètes, partielles et les fichiers restaurés ; contrôle des compteurs et des listes dans les vues WPF.

Pour installer ce correctif : **Paramètres > Vérifier les mises à jour**, ou téléchargez l’installateur ou l’archive portable ci-dessous.
