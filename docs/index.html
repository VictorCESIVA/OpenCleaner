Un nettoyage commence par une décision éclairée. OpenCleaner vous accompagne à chaque étape.

Une analyse ne supprime
aucun fichier.
  1. 01

    Analysez votre PC

    Lancez « Analyser mon PC » pour un premier tri, ou choisissez une catégorie. L’analyse ne supprime aucun fichier.

  2. 02

    Vérifiez les résultats

    Consultez les éléments et leur niveau de risque. Sélectionnez ceux que vous souhaitez nettoyer. Sans sélection, tous les résultats affichés sont concernés.

  3. 03

    Confirmez le nettoyage

    Les suppressions de fichiers passent par des contrôles et une sauvegarde locale vérifiée.

Et les sauvegardes ? Elles restent sur votre disque et occupent de l’espace jusqu’à leur suppression dans Restauration. Avec une sauvegarde sur le même disque, le nettoyage ne libère donc pas immédiatement le volume annoncé par l’analyse.

Est-ce vraiment gratuit ? +

Oui. OpenCleaner est gratuit et open source sous licence MIT. Aucun abonnement et aucune publicité dans l’application.

De quoi ai-je besoin pour l’utiliser ? +

D’un PC Windows 10 ou Windows 11 en 64 bits. L’installateur inclut le nécessaire pour fonctionner. Une version portable est aussi disponible : décompressez l’archive, puis lancez OpenCleaner.UI.exe. Retrouvez les fichiers et les notes de version sur GitHub Releases.

Mes fichiers sont-ils supprimés automatiquement ? +

Une analyse ne supprime rien. Vous examinez les résultats, puis confirmez le nettoyage. Si vous activez la planification dans l’application, elle se limite aux fichiers à faible risque des catégories autorisées.

Comment restaurer un fichier nettoyé ? +

Ouvrez Restauration dans OpenCleaner pour retrouver les sauvegardes encore conservées. Elles sont locales, chiffrées avec une clé liée à votre compte Windows, et un code de récupération permet de retrouver l’accès en cas de perte : conservez-le en lieu sûr. Ces copies ne remplacent pas une sauvegarde indépendante. Le vidage de la corbeille et l’effacement sécurisé ne créent pas de sauvegarde OpenCleaner ; sur SSD, l’effacement définitif ne peut pas être garanti. Les exports du registre se réimportent manuellement.

Peut-on changer la langue et le thème ? +

Oui. Le français et l’anglais sont disponibles depuis Paramètres > Langue, sans redémarrage. Le thème clair ou sombre se choisit dans la barre latérale. La nouvelle interface respecte le réglage d’animations de Windows.

Comment mettre OpenCleaner à jour ? +

Dans Paramètres, choisissez Vérifier les mises à jour. Les versions installées recherchent aussi les mises à jour au démarrage. L’application demande votre accord avant de redémarrer pour appliquer une mise à jour. Pour une version portable, téléchargez la nouvelle archive depuis GitHub Releases.

Pourquoi Windows affiche-t-il un avertissement ? +

SmartScreen peut afficher un avertissement si le binaire téléchargé n’est pas signé. Vérifiez sa provenance et consultez les notes de version sur le dépôt officiel. Le caractère open source ne garantit pas, à lui seul, la sûreté d’un fichier téléchargé.

OpenCleaner remplace-t-il un antivirus ? +

Non. L’outil de confidentialité repère certaines traces et des fichiers potentiellement sensibles, qui demandent une vérification manuelle. OpenCleaner n’est pas un antivirus.
